# 旅游助手 - 数据表设计

## 一、对话记录表

### 表名：旅游助手对话记录表

### 表结构

| 字段名 | 字段类型 | 说明 | 是否必填 | 默认值 |
|--------|----------|------|----------|--------|
| 用户问题 | 多行文本 | 用户提问的内容 | 是 | - |
| Bot回复 | 多行文本 | AI智能体的回复内容 | 是 | - |
| 是否FAQ | 单选 | 是否标记为FAQ（是/否） | 是 | 否 |
| 提问时间 | 日期 | 用户提问的时间 | 是 | 当前时间 |
| 问题分类 | 单选 | 问题类型分类 | 否 | - |

- 美食推荐

## 四、自动化流程配置说明

### 对话记录 → FAQ 同步流程

**触发条件**：当"对话记录表"中某条记录的"是否FAQ"字段被修改为"是"时触发

**操作步骤**：
1. 触发：当对话记录表内容变更
2. 条件：是否FAQ 等于 "是"
3. 动作：在"旅游FAQ知识库"表中新增一条记录
   - 常见问题 = 触发记录的"用户问题"
   - 标准答案 = 触发记录的"Bot回复"
   - 分类 = 触发记录的"问题分类"
   - 添加时间 = 当前时间

**注意**：此流程用于自动将高频优质问答同步到FAQ知识库，实现知识的持续积累和自动更新。
