# 旅游助手智能体 - 项目材料说明

## 项目简介

本项目是基于扣子（Coze）平台开发的旅游助手智能体，为用户提供专业的旅游咨询服务，包括景点推荐、美食攻略、住宿建议、交通指南、行程规划等功能。

## 快速开始

### 第一步：创建多维表格

1. 参考 `docs/数据表设计.md` 创建两张数据表：
   - 旅游助手对话记录表
   - 旅游FAQ知识库

2. 配置自动化流程：当对话记录表中的"是否FAQ"变为"是"时，自动同步到FAQ知识库表

### 第二步：创建知识库

1. **文档知识库**：
   - 创建文档类型知识库，命名"旅游攻略知识库"
   - 上传 `knowledge-base/国内热门城市旅游攻略.md`（或转成Word后上传）

2. **表格知识库**：
   - 创建表格类型知识库，命名"旅游FAQ知识库"
   - 导入多维表格中的FAQ表
   - 设置"常见问题"为索引字段
   - 设置定期同步

### 第三步：配置对话流

参考 `workflow-config/对话流设计说明.md`，按顺序配置11个节点：

1. 开始节点
2. 意图识别节点（2个意图：旅游相关/非旅游相关）
3. 大模型_1节点（问题改写，用 `prompts/rewrite_prompt.md`）
4. 知识库节点（关联两个知识库）
5. 大模型节点（回复生成，用 `prompts/travel_assistant_prompt.md`）
6. 代码节点（用 `code/code_node.js`）
7. add_records节点（写入对话记录表）
8. 输出1节点
9. 大模型_2节点（闲聊，用 `prompts/chat_prompt.md`）
10. 输出节点
11. 结束节点

### 第四步：测试发布

1. 测试各个功能模块
2. 验证对话记录保存和FAQ同步
3. 发布智能体

## 功能亮点

1. **意图识别**：自动区分旅游相关和非旅游问题
2. **RAG检索增强**：结合知识库和大模型，回答准确专业
3. **问题改写**：结合上下文理解用户真实意图
4. **双知识库**：文档知识库+表格知识库，覆盖全面
5. **自动知识积累**：对话记录可标记为FAQ，自动同步更新知识库
6. **对话数据记录**：所有对话自动保存，便于数据分析和优化

## 考核要点对照

| 考核项 | 对应实现 |
|--------|----------|
| 需求分析 | 明确的功能定位、目标用户、使用场景 |
| 智能体结构设计 | 11个节点，结构清晰，模块划分明确 |
| 工作流设计 | 完整的对话流程，逻辑顺畅 |
| 节点类型 | 开始、意图识别、大模型×3、知识库、代码、添加记录、输出×2、结束 |
| 插件/集成 | 多维表格插件（add_records） |
| 数据库设计 | 对话记录表+FAQ表，结构合理 |
| 知识库设计 | 文档知识库+表格知识库，双库联动 |
| 多平台协同 | 扣子+多维表格，数据双向同步 |
| 提示词 | 3组提示词，规范专业 |
| 代码 | 代码节点数据格式化 |

## 注意事项

1. 上传知识库文档时，建议使用 Word 格式（.docx），兼容性更好
2. FAQ表格数据可以先导入几条示例数据测试
3. 提示词可以根据实际测试效果进行调整优化
4. 设计报告中的截图需要自己在扣子平台操作时截取
5. 视频演示需要自己录制
