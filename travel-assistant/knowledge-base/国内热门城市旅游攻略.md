## 北京市旅游攻略

### 一、景点推荐

#### 必去经典景点

1. **故宫博物院**
   - 简介：明清两代的皇家宫殿，世界五大宫之首，世界文化遗产
   - 门票：旺季（4-10月）60元，淡季（11-3月）40元
   - 开放时间：旺季 8:30-17:00，淡季 8:30-16:30，周一闭馆
   - 建议游玩时间：4-5小时
   - 交通：地铁1号线天安门东站/西站
   - 贴士：提前7天在官网预约，建议租讲解器

2. **八达岭长城**
   - 简介：明长城中保存最好的一段，"不到长城非好汉"
   - 门票：旺季40元，淡季35元
   - 开放时间：旺季 7:30-18:00，淡季 7:30-17:30
   - 建议游玩时间：3-4小时
   - 交通：德胜门乘877路直达，或S2线火车到八达岭站
   - 贴士：穿舒适的鞋子，建议坐滑车/缆车省力

3. **天安门广场**
   - 简介：世界最大的城市中心广场
   - 门票：免费
   - 开放时间：全天
   - 建议游玩时间：1-2小时
   - 贴士：观看升旗需提前查好时间，提前到达

4. **颐和园**
   - 简介：中国现存最大的皇家园林，世界文化遗产
   - 门票：旺季30元，淡季20元
   - 开放时间：旺季 6:30-18:00，淡季 7:00-17:00
   - 建议游玩时间：3-4小时
   - 交通：地铁4号线北宫门站
   - 贴士：夏季荷花盛开，秋季红叶很美

5. **天坛公园**
   - 简介：明清皇帝祭天、祈谷的场所
   - 门票：旺季15元，淡季10元
   - 开放时间：6:00-22:00
   - 建议游玩时间：2-3小时
   - 交通：地铁5号线天坛东门站

#### 其他推荐景点
- 圆明园：遗址公园，门票25元
- 恭王府：清代和珅府邸，门票40元
- 南锣鼓巷：老北京胡同文化，免费
- 798艺术区：文艺打卡地，免费
- 鸟巢/水立方：奥运场馆，外观免费，入内收费

### 二、美食推荐

#### 北京特色美食
1. **北京烤鸭**：全聚德、大董、四季民福、便宜坊
2. **炸酱面**：海碗居、方砖厂69号
3. **涮羊肉**：东来顺、聚宝源
4. **豆汁儿焦圈**：护国寺小吃
5. **卤煮火烧**：门框胡同百年卤煮
6. **爆肚**：爆肚冯、金生隆

#### 美食街推荐
- 簋街：夜宵一条街，小龙虾、火锅
- 南锣鼓巷：各种小吃、网红店
- 牛街：清真美食，牛羊肉、糕团
- 护国寺街：传统北京小吃

### 三、住宿推荐

#### 热门住宿区域
1. **王府井/东单**：市中心，购物方便，交通便利，价格偏高
2. **前门/大栅栏**：靠近天安门，老北京风情，选择多样
3. **西单**：年轻人聚集地，商场多，交通方便
4. **三里屯**：时尚潮流，酒吧多，夜生活丰富
5. **中关村/五道口**：高校区，性价比高

#### 酒店推荐
- 高端：北京饭店、王府半岛酒店
- 中端：全季、亚朵、桔子水晶
- 经济：如家、汉庭、7天连锁

### 四、交通指南

- **机场**：首都国际机场（地铁机场线）、大兴国际机场（大兴机场线）
- **火车站**：北京站、北京西站、北京南站、北京北站
- **地铁**：覆盖全市，是最佳出行方式，票价2元起
- **公交**：线路众多，刷码乘车
- **打车**：起步价13元，建议网约车

### 五、最佳旅游时间
- 春季（4-5月）：春暖花开，气候宜人
- 秋季（9-10月）：秋高气爽，红叶满山
- 夏季炎热，冬季寒冷但可看雪景

## 上海市旅游攻略

### 一、景点推荐

#### 必去经典景点

1. **外滩**
   - 简介：上海标志性景观，万国建筑博览群
   - 门票：免费
   - 建议游玩时间：1-2小时
   - 贴士：夜景最美，建议傍晚去

2. **东方明珠**
   - 简介：上海地标，电视塔观光
   - 门票：观光层160元起，旋转餐厅398元起
   - 开放时间：9:00-21:00
   - 交通：地铁2号线陆家嘴站

3. **豫园**
   - 简介：江南古典园林，明代私家园林
   - 门票：旺季40元，淡季30元
   - 开放时间：9:00-17:00
   - 交通：地铁10号线豫园站
   - 贴士：旁边就是城隍庙，可以一起逛

4. **迪士尼乐园**
   - 简介：中国大陆首座迪士尼主题乐园
   - 门票：平日约435元，高峰日约599元
   - 开放时间：一般 9:00-21:30
   - 交通：地铁11号线迪士尼站
   - 贴士：提前下载官方APP，抢快速通行证

5. **南京路步行街**
   - 简介：中华商业第一街
   - 门票：免费
   - 交通：地铁1/2/8号线人民广场站

#### 其他推荐景点
- 上海博物馆：免费，需预约
- 田子坊：文艺弄堂，免费
- 朱家角古镇：江南水乡，免费
- 上海中心大厦：登高观景，门票180元
- 新天地：石库门建筑，时尚街区

### 二、美食推荐

#### 上海特色美食
1. **小笼包**：南翔小笼、富春小笼
2. **生煎馒头**：小杨生煎、大壶春
3. **蟹粉豆腐**：上海本帮菜经典
4. **红烧肉**：本帮菜代表
5. **白斩鸡**：振鼎鸡、小绍兴
6. **鲜肉月饼**：中秋前后必吃

#### 美食街推荐
- 南京路：老字号云集
- 城隍庙/豫园：小吃众多
- 云南南路：美食街
- 黄河路：美食街

### 三、住宿推荐

#### 热门住宿区域
1. **外滩/南京路**：市中心，景观好，价格高
2. **人民广场**：交通枢纽，出行方便
3. **陆家嘴**：金融中心，高端酒店多
4. **静安寺**：商圈繁华，中高档
5. **徐家汇**：交通便利，性价比高

### 四、交通指南

- **机场**：浦东国际机场（地铁2号线/磁悬浮）、虹桥国际机场（地铁2/10号线）
- **火车站**：上海站、上海虹桥站、上海南站
- **地铁**：线路密集，覆盖广，票价3元起
- **公交**：2元起
- **轮渡**：黄浦江两岸交通，票价便宜

### 五、最佳旅游时间
- 春季（3-5月）：气候宜人
- 秋季（9-11月）：秋高气爽
- 夏季炎热，冬季湿冷

## 成都市旅游攻略

### 一、景点推荐

#### 必去经典景点

1. **大熊猫繁育研究基地**
   - 简介：看国宝大熊猫的最佳地点
   - 门票：55元
   - 开放时间：7:30-18:00
   - 建议游玩时间：3-4小时
   - 交通：地铁3号线熊猫大道站转公交
   - 贴士：早上8-10点熊猫最活跃，建议早去

2. **宽窄巷子**
   - 简介：老成都缩影，由宽巷子、窄巷子、井巷子组成
   - 门票：免费
   - 建议游玩时间：2-3小时
   - 交通：地铁4号线宽窄巷子站

3. **锦里古街**
   - 简介：武侯祠旁的仿古商业街，夜景很美
   - 门票：免费
   - 建议游玩时间：2-3小时
   - 交通：地铁3号线高升桥站
   - 贴士：晚上去更有氛围，红灯笼很漂亮

4. **武侯祠**
   - 简介：纪念诸葛亮的祠堂，三国文化圣地
   - 门票：50元
   - 开放时间：8:00-20:00
   - 建议游玩时间：1-2小时

5. **杜甫草堂**
   - 简介：杜甫故居，唐代诗圣的茅屋
   - 门票：50元
   - 开放时间：8:00-18:00
   - 建议游玩时间：2小时

#### 周边推荐
- **都江堰**：古代水利工程，门票80元，高铁约30分钟
- **青城山**：道教名山，门票80元，距都江堰约1小时
- **峨眉山**：四大佛教名山，高铁约1.5小时
- **九寨沟**：童话世界，较远，建议跟团或自驾

### 二、美食推荐

#### 成都必吃美食
1. **火锅**：蜀大侠、小龙坎、大龙燚、谭鸭血、海底捞
2. **串串香**：钢管厂五区、马路边边、康二姐
3. **担担面**：陈麻婆豆腐店、成都担担面
4. **龙抄手**：龙抄手总店
5. **夫妻肺片**：夫妻肺片总店
6. **兔头**：双流老妈兔头
7. **钟水饺**：钟水饺总店
8. **冒菜**：各种冒菜店

#### 美食街推荐
- 锦里：小吃集中
- 宽窄巷子：有一些特色餐厅
- 建设路：学生美食街
- 玉林：串串、火锅聚集地
- 春熙路：商圈美食多

### 三、住宿推荐

#### 热门住宿区域
1. **春熙路/太古里**：市中心，购物便利，交通方便
2. **宽窄巷子附近**：老成都风情，逛景点方便
3. **锦里/武侯祠附近**：靠近景点
4. **天府广场**：地铁枢纽，出行便利

### 四、交通指南

- **机场**：双流国际机场（地铁10号线）、天府国际机场（地铁18号线）
- **火车站**：成都站、成都东站、成都南站
- **地铁**：线路覆盖广，票价2元起
- **公交**：2元起
- **打车**：起步价8元

### 五、最佳旅游时间
- 春季（3-5月）：春暖花开
- 秋季（9-11月）：气候舒适
- 夏季湿热，冬季湿冷
- 常年阴天多，有"蜀犬吠日"之说

## 西安市旅游攻略

### 一、景点推荐

#### 必去经典景点

1. **秦始皇兵马俑博物馆**
   - 简介：世界第八大奇迹，世界文化遗产
   - 门票：120元
   - 开放时间：旺季 8:30-18:00，淡季 8:30-17:30
   - 建议游玩时间：3-4小时
   - 交通：西安北站坐高铁到临潼站，或乘坐游5路
   - 贴士：请个讲解员更有意思，1号坑最壮观

2. **西安城墙**
   - 简介：中国现存规模最大、保存最完整的古城墙
   - 门票：54元
   - 开放时间：8:00-22:00
   - 建议游玩时间：2-3小时（建议租自行车骑行）
   - 贴士：傍晚去，可以看白天和夜景两种景色

3. **大雁塔/大唐不夜城**
   - 简介：唐代古塔，旁边是大唐不夜城步行街
   - 门票：大慈恩寺50元，登塔30元
   - 开放时间：8:00-18:30
   - 交通：地铁3/4号线大雁塔站
   - 贴士：大唐不夜城晚上去，灯光秀很漂亮

4. **回民街**
   - 简介：西安美食聚集地，回族风情街
   - 门票：免费
   - 建议游玩时间：2-3小时
   - 交通：地铁2号线钟楼站

5. **钟楼/鼓楼**
   - 简介：西安地标，晨钟暮鼓
   - 门票：单票30元，联票50元
   - 开放时间：8:30-21:00
   - 交通：地铁2号线钟楼站

#### 其他推荐景点
- 华清宫：唐代行宫，门票120元
- 陕西历史博物馆：免费但需预约，文物众多
- 永兴坊：美食街，摔碗酒
- 华山：五岳之西岳，高铁约30分钟

### 二、美食推荐

#### 西安必吃美食
1. **肉夹馍**：腊汁肉夹馍、老潼关肉夹馍
2. **羊肉泡馍**：老孙家、同盛祥
3. **凉皮**：秦镇米皮、擀面皮、麻酱凉皮
4. **biangbiang面**：陕西特色宽面
5. **臊子面**：酸辣可口
6. **甑糕**：回民街早点
7. **红柳烤肉**：羊肉串
8. **酸梅汤**：解腻必备

#### 美食街推荐
- 回民街/北院门：游客必去
- 永兴坊：陕西各地美食
- 大皮院：本地人常去
- 洒金桥：美食更多更地道

### 三、住宿推荐

#### 热门住宿区域
1. **钟鼓楼/回民街附近**：市中心，美食多，逛景点方便
2. **大雁塔/曲江附近**：环境好，夜景美
3. **永宁门/城墙附近**：靠近城墙
4. **小寨**：商圈繁华，交通便利

### 四、交通指南

- **机场**：咸阳国际机场（地铁14号线）
- **火车站**：西安站、西安北站（高铁）
- **地铁**：线路逐渐完善，票价2元起
- **公交**：2元起
- **共享单车**：很方便

### 五、最佳旅游时间
- 春季（3-5月）：春暖花开
- 秋季（9-11月）：秋高气爽
- 夏季炎热，冬季寒冷

## 厦门市旅游攻略

### 一、景点推荐

#### 必去经典景点

1. **鼓浪屿**
   - 简介：海上花园，万国建筑博览
   - 门票：船票35元（往返），景点单独收费
   - 开放时间：全天
   - 建议游玩时间：1天
   - 交通：轮渡码头坐船前往，需提前预约
   - 贴士：避开节假日，岛上步行游览

2. **厦门大学**
   - 简介：中国最美大学之一
   - 门票：免费，需预约
   - 开放时间：周末、寒暑假、节假日对公众开放
   - 交通：地铁1号线厦大站
   - 贴士：芙蓉隧道、上弦场必打卡

3. **南普陀寺**
   - 简介：闽南佛教圣地
   - 门票：免费
   - 开放时间：6:00-20:00
   - 建议游玩时间：1-2小时
   - 贴士：素饼很有名，可以买来当伴手礼

4. **环岛路**
   - 简介：最美马拉松赛道
   - 门票：免费
   - 建议游玩时间：半天
   - 交通：公交或共享单车
   - 贴士：租辆自行车骑行，白城沙滩、曾厝垵都在沿线

5. **曾厝垵**
   - 简介：文艺渔村，民宿聚集地
   - 门票：免费
   - 建议游玩时间：2-3小时
   - 贴士：晚上去更热闹

#### 其他推荐景点
- 沙坡尾：文艺打卡地
- 集美学村：嘉庚建筑
- 胡里山炮台：海岸炮台
- 植物园：拍照圣地，雨林世界、多肉区

### 二、美食推荐

#### 厦门必吃美食
1. **沙茶面**：乌糖沙茶面、月华沙茶面
2. **海蛎煎**：莲欢海蛎煎
3. **土笋冻**：闽南特色，章鱼小丸子的祖宗
4. **花生汤**：黄则和花生汤
5. **面线糊**：早餐首选
6. **姜母鸭**：滋补美食
7. **烧肉粽**：烧肉粽店
8. **椰子饼**：伴手礼

#### 美食街推荐
- 曾厝垵：小吃多
- 中山路：步行街，老字号
- 八市：本地人市场，海鲜多
- 鼓浪屿龙头路：游客美食街

### 三、住宿推荐

#### 热门住宿区域
1. **鼓浪屿**：岛上民宿，体验海岛风情
2. **环岛路/曾厝垵**：海景民宿，文艺范
3. **中山路/轮渡**：交通便利，去鼓浪屿方便

## 旅游通用贴士

### 出行前准备
1. 提前查好天气，带合适的衣物
2. 提前订好酒店和门票，节假日更要提前
3. 带好身份证、学生证（有优惠）
4. 下载当地地铁公交APP
5. 准备一些常用药品

### 安全注意事项
1. 保管好贵重物品，人多的地方注意防盗
2. 不要轻易相信路边拉客的
3. 选择正规渠道购票
4. 注意饮食卫生
5. 结伴出行更安全

### 省钱小贴士
1. 提前订机票酒店更便宜
2. 学生证、老年证很多景点有优惠
3. 错峰出行价格更低
4. 住青旅或民宿更经济
5. 当地公共交通比打车便宜
