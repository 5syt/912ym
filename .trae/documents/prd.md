## 1. 产品概述
- 2026计网知识点刷题网页，面向计算机网络课程学生，提供选择题、判断题、简答题、计算题等多种题型的在线练习与标准答案对照
- 帮助学生高效复习计算机网络核心知识点，通过交互式答题提升学习效果

## 2. 核心功能

### 2.1 功能模块
1. **刷题主页**: 题型分类导航（选择题/判断题/简答题/画图与计算题/应用与分析题）、答题进度统计
2. **选择题页面**: 单选答题、即时判对错、显示标准答案与解析
3. **判断题页面**: 对/错选择、即时反馈、显示解析
4. **简答题页面**: 查看题目、显示/隐藏标准答案、关键词高亮
5. **计算题页面**: 查看题目、显示/隐藏详细解题过程与答案

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 刷题主页 | 题型导航卡片 | 展示5种题型入口，显示各题型题目数量 |
| 刷题主页 | 进度统计 | 显示已答题数、正确率等统计信息 |
| 选择题 | 题目展示与答题 | 展示题目和选项，点击选择，提交后显示对错 |
| 选择题 | 答案解析 | 显示正确答案、解析说明 |
| 判断题 | 对错判断 | 展示题目，选择对/错，提交后显示结果 |
| 简答题 | 答案对照 | 展示题目，点击显示标准答案 |
| 计算题 | 解题过程 | 展示题目，点击显示分步解题过程 |

## 3. 核心流程
用户打开网页 → 选择题型 → 逐题作答 → 提交答案查看结果 → 查看标准答案与解析 → 继续下一题或切换题型

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝(#1e3a5f) + 亮绿(#10b981)作为强调色，营造学术且现代的氛围
- 按钮样式：圆角矩形，hover时微动效
- 字体：标题使用Noto Sans SC Bold，正文使用Noto Sans SC Regular
- 布局风格：左侧固定导航 + 右侧答题区域，卡片式题目展示
- 图标：使用lucide-react图标库

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 刷题主页 | 题型导航 | 5张渐变背景卡片，悬停缩放效果，显示题型名和题目数 |
| 选择题 | 答题卡片 | 白色卡片，4个选项按钮，选中高亮，提交后正确绿色/错误红色 |
| 判断题 | 对错按钮 | 两个大按钮（对✓/错✗），选中态明显 |
| 简答题 | 折叠答案 | 白色卡片 + "显示答案"按钮，点击展开答案区域 |
| 计算题 | 步骤展开 | 白色卡片 + "显示解题过程"按钮，分步展示 |

### 4.3 响应式设计
- 桌面端优先，移动端自适应
- 答题区域最大宽度800px居中
