# 基于Selenium+Python的豆瓣读书自动化测试实战 - Verification Checklist

## 项目结构检查
- [x] 项目根目录命名为 AutoTestProject01（或 AutoTestProject+学号后两位）
- [x] 包含 base 目录，存放 BasePage 基类
- [x] 包含 page 目录，存放各 Page Object 页面类
- [x] 包含 testcase 目录，存放测试用例文件
- [x] 包含 data 目录，存放 JSON 测试数据文件
- [x] 包含 report 目录，存放测试报告

## 代码结构与设计模式检查
- [x] BasePage 基类封装了元素查找、点击、输入、获取文本等通用方法
- [x] BasePage 基类封装了显式等待（WebDriverWait）相关方法

- [x] 所有页面类均继承自 BasePage
